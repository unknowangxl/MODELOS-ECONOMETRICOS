Software desarrollado para la calculadora gráfica HP Prime, orientado a facilitar y automatizar la resolución de cálculos estadísticos y econométricos correspondientes a la asignatura **Modelos Econométricos (SIS 3540)**.

El proyecto busca implementar herramientas de cálculo para los diferentes temas de la materia, incluyendo regresión lineal simple y múltiple, regresión polinomial, análisis de correlación, pruebas de hipótesis, intervalos de confianza, predicción de modelos y análisis de heterocedasticidad, autocorrelación y multicolinealidad.

El objetivo es proporcionar una herramienta práctica, organizada y accesible que permita introducir datos, realizar operaciones matemáticas y obtener resultados directamente desde la HP Prime, facilitando tanto el desarrollo de ejercicios académicos como el aprendizaje de los modelos econométricos.

**Plataforma:** HP Prime Graphing Calculator  
**Lenguaje:** HP PPL (Prime Programming Language)
